Visual Studio Code，简称 VS Code，是一个代码编辑器。你可以用它编写程序和文档、管理项目文件，并在同一个窗口中使用终端和 Git 等工具。

这篇文档不要求你记住所有按钮。我们的目标是先建立一个正确的使用习惯：**打开完整文件夹，在明确的项目范围内工作。**

## 第一步：打开文件夹

启动 VS Code 后，选择菜单中的“文件 → 打开文件夹”，然后选择你要学习或开发的项目文件夹。

打开文件夹后，VS Code 会把它视为当前工作区。左侧资源管理器会显示这个文件夹中的全部内容，终端也可以从该文件夹开始运行命令。

只打开单个文件虽然可以临时编辑文字，但会失去一部分项目级能力。处理课程代码或项目时，优先打开完整文件夹。

### 关于工作区信任

打开从网络下载或他人提供的项目时，VS Code 可能询问你是否信任该文件夹。信任项目后，扩展、任务和调试配置可能获得执行代码的能力。

如果你不清楚项目来源，先不要直接信任和运行。确认文件来自可信来源，或请了解项目的人帮助检查。

## 认识主要界面

VS Code 的界面可以先理解为五个区域：

1. **活动栏**：切换资源管理器、搜索、源代码管理、运行和扩展等功能。
2. **侧边栏**：显示当前功能的具体内容，例如项目文件树。
3. **编辑区**：阅读和修改文件的主要区域。
4. **面板**：显示终端、输出、问题和调试信息。
5. **状态栏**：显示当前文件、Git 分支、错误数量等状态。

界面布局可以调整。刚开始时建议保留默认布局，先理解每个区域解决什么问题。

## 使用资源管理器

点击活动栏中的资源管理器图标，可以查看当前项目的文件树。

你可以在这里：

- 创建文件和文件夹。
- 重命名或移动文件。
- 展开目录并打开文件。
- 通过右键菜单在指定目录中打开终端。

修改前先确认文件位于哪个目录。项目中可能存在同名文件，路径往往比文件名更能说明它的用途。

## 查找文件和内容

当项目文件增多后，不要只依靠逐层展开文件夹。

- 按 `Ctrl + P`，可以按文件名快速打开文件。
- 按 `Ctrl + Shift + F`，可以在当前文件夹中搜索文字。
- 按 `Ctrl + F`，可以在当前文件中搜索。

全局搜索适合寻找某段文案、函数名或配置项在哪里出现。修改公共名称前，也可以先搜索它被哪些文件使用。

## 使用命令面板

按 `Ctrl + Shift + P` 可以打开命令面板。许多不熟悉位置的功能都可以通过输入名称找到。

例如，你可以搜索：

- `Format Document`：格式化当前文档。
- `Preferences: Open Settings`：打开设置。
- `Developer: Reload Window`：重新加载 VS Code 窗口。

不必记住大量菜单路径。知道功能名称时，命令面板通常是更直接的入口。

## 打开集成终端

选择“查看 → 终端”，或者按 `` Ctrl + ` ``，可以在 VS Code 底部打开集成终端。

终端通常会从当前工作区根目录开始。运行命令前，先确认终端提示符显示的目录是否正确。

终端可以用于：

- 运行程序和开发服务器。
- 执行项目检查或构建命令。
- 使用 Git 查看和保存版本。
- 查看工具输出和报错。

不要执行自己无法判断作用的删除、覆盖或系统配置命令。从网页或聊天中复制命令时，应先了解它会读取、创建、修改还是删除什么。

## 安装扩展

按 `Ctrl + Shift + X` 可以打开扩展视图。扩展能够为特定语言、框架或工具增加语法提示、格式化和调试等能力。

安装扩展前，建议检查：

- 发布者是否可信或得到课程、项目的明确推荐。
- 扩展解决的问题是否是你当前确实需要的。
- 是否与已经安装的同类扩展功能重复。

扩展并不是越多越好。数量过多可能增加启动时间，也可能让格式化和代码提示规则相互冲突。

## 完成一次基础练习

你可以用下面的任务确认自己已经掌握基础操作：

1. 新建一个练习文件夹，并使用 VS Code 打开它。
2. 在资源管理器中创建 `README.md`。
3. 写入一个标题和一段说明。
4. 使用 `Ctrl + P` 再次找到这个文件。
5. 使用全局搜索找到刚才写入的某个词。
6. 打开集成终端，确认终端当前位于练习文件夹。
7. 打开命令面板，找到“格式化文档”命令。

完成这些操作后，你已经能够把 VS Code 作为项目编辑器使用。后续学习某种编程语言时，再根据课程和项目需要补充对应扩展、运行环境和调试方法。
