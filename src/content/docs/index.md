大家好，这里是武汉科技大学人工智能与自动化学院学生科协。

本网站通过 Vibe Coding 制作。我们欢迎浏览者通过 [GitHub Issues](https://github.com/icewater721/automation-science-association-website/issues) 提出建议。目前开发者能力有限，暂不接收 Pull Request，敬请谅解。

## 关于科协

此介绍主要面向本院学生。

主页已经提供了科协的基本介绍。在这里，我们还想说明：科协目前仍处于建设阶段，欢迎对科协感兴趣的同学加入。我们希望让更多有趣的想法变成现实，并正在为此努力。

## 提交 Issue

Issue 用于帮助项目改进功能、布局和内容等。提交 Issue 前，请检查：

- Issue 是否有明确指向。
- 是否已经有人提出过类似 Issue。
