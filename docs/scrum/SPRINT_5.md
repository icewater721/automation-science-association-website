# Sprint 5：统一全站搜索

## 状态

进行中。开始日期：2026-08-22。

## Sprint Goal

统一并优化全站搜索，使访客能够通过侧栏搜索同时找到仓库内置文档与 Supabase 已发布文章，并获得一致、清晰的搜索反馈。

## 用户价值

目前静态 Markdown 会进入构建时搜索索引，但用户发布的数据库文章不会。完成本轮后，访客不必知道内容存放在哪里，只需要输入关键词即可查询全站公开内容。

## Sprint Backlog

- [ ] 盘点当前静态搜索索引和 Supabase 公开文章 Feed。
- [ ] 设计统一的搜索结果数据结构。
- [ ] 将已发布的 Supabase 文章加入搜索范围。
- [ ] 保持标题、分类、摘要和关键词的匹配逻辑一致。
- [ ] 处理加载中、无结果、网络失败和重复结果。
- [ ] 检查搜索结果链接在 GitHub Pages 子路径下正确跳转。
- [ ] 验收浅色、深色和键盘操作。
- [ ] 更新搜索架构、维护说明和 Product Backlog。
- [ ] 完成格式、类型和生产构建检查。
- [ ] 完成 Sprint Review、学习回顾与 Retrospective。

## 暂不纳入本轮

- 评论系统
- 活动与服务模块
- 手机端整体重构
- 正式域名
- 文章编辑器技术债重构

## Definition of Done

- 同一个搜索框可找到静态文档和已发布数据库文章。
- 草稿、未发布文章和无权限内容不会出现在公开搜索中。
- 搜索结果没有因双来源造成明显重复。
- 网络失败时静态搜索仍尽可能可用，并给出可理解提示。
- 搜索可用键盘操作，结果链接正确。
- `pnpm format:check`、`pnpm check` 与 `pnpm build` 通过。
- 相关文档与 Backlog 同步更新。
