# Sprint 5：待规划

## 状态

规划中。创建日期：2026-08-22。

## Sprint Goal

待 Product Owner 在 Sprint Planning 中确认。只选择一个主要成果，避免像 Sprint 4 一样同时扩张多个大型方向。

## 候选方向

- 统一动态文章与静态文档的全站搜索。
- 手机端适配、键盘操作与无障碍验收。
- 替换文章编辑器中已弃用的 `document.execCommand`。
- 建设活动或服务内容。
- 建立数据库迁移与发布验收清单/自动化。

## 进入 Sprint 前必须确认

1. 主要用户问题是什么？
2. 本轮唯一的 Sprint Goal 是什么？
3. 哪些事项明确不进入本轮？
4. 如何验收，哪些页面和权限流程必须测试？
5. 最新 Supabase 迁移是否已经在线上执行？

## Definition of Done

- Sprint Goal 的验收标准全部满足。
- 相关代码、数据库迁移和文档保持同步。
- `pnpm format:check`、`pnpm check` 与 `pnpm build` 通过。
- 公网页面和相关身份角色完成验收。
- 完成 Sprint Review、学习回顾与 Retrospective。
