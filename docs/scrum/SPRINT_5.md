# Sprint 5：统一全站搜索与社区成员目录

## 状态

进行中。开始日期：2026-08-22。

## Sprint Goal

统一并优化全站搜索，使访客能够通过侧栏搜索同时找到仓库内置文档与 Supabase 已发布文章，并获得一致、清晰的搜索反馈。

## 次要成果：社区成员目录

在左侧栏加入“社区”入口，提供管理员发现与联系信息。短期只解决“用户如何找到管理员”，不建设站内交流系统。

## 用户价值

本轮开始时，静态 Markdown 会进入构建时搜索索引，但用户发布的数据库文章不会。完成后，访客不必知道内容存放在哪里，只需要输入关键词即可查询全站公开内容。同时，用户可以通过社区页识别管理员并找到经允许公开的联系途径。

## Definition of Done

- 同一个搜索框可找到静态文档和已发布数据库文章。
- 草稿、未发布文章和无权限内容不会出现在公开搜索中。
- 搜索结果没有因双来源造成明显重复。
- 网络失败时静态搜索仍尽可能可用，并给出可理解提示。
- 搜索可用键盘操作，结果链接正确。
- 访客可从侧栏进入社区页，并通过公开信息找到管理员。
- 社区页不会泄露未明确允许公开的账号或联系方式。
- `pnpm format:check`、`pnpm check` 与 `pnpm build` 通过。
- 相关文档与 Backlog 同步更新。
