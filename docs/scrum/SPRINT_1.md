- 键盘操作与基础无障碍专项检查：转入后续迭代。
- 手机端布局与折叠菜单：获得正式域名、便于真机访问后再验收。

## Sprint 1 Definition of Done

- 占位页被完整主页 MVP 替换。
- `pnpm check` 与 `pnpm build` 成功。
- 主页完成桌面端验收；手机端真机验收转入获得正式域名后的迭代。
