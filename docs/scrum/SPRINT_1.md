# Sprint 1：可运行的主页骨架

## Sprint Goal

建立可运行、可检查的 Astro 项目，并实现主页的全局结构、双主题基础和响应式导航。

## 计划周期

建议 1 周。开始日期以正式开工日为准。

## Sprint Backlog

- [x] 确认 Astro 静态架构
- [x] 初始化 Astro、TypeScript 与格式检查
- [x] 初始化 Git 并连接 GitHub 远程仓库
- [x] 建立品牌资源目录与全局设计变量
- [x] 实现 BaseLayout 与主题初始化
- [ ] 实现 Header、ThemeToggle 与移动导航
- [ ] 实现主页区块骨架
- [ ] 建立结构化内容模型与示例内容
- [ ] 完成桌面端与移动端检查
- [x] 运行类型检查和生产构建

## Sprint 1 Definition of Done

- 新成员按 README 可以启动开发环境。
- `pnpm check` 与 `pnpm build` 成功。
- 主页在桌面端和移动端均无页面级横向滚动。
- 浅色与深色主题可用，导航栏与页面主体反色。
- 主页包含已确认的全部信息区块骨架。
- 内容与组件代码分离。
- 代码进入 Git 历史并可在 GitHub 上评审。
