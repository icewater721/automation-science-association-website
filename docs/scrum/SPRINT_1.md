# Sprint 1：主页 MVP

## 状态

进行中。开始日期：2026-08-16。

## Sprint Goal

把占位页替换为可浏览的主页 MVP，实现完整信息结构、三种外观模式和响应式导航，为后续填入真实内容做好准备。

## 计划周期

1 周。

## Sprint Backlog

- [ ] 建立主页内容模型与示例内容
- [ ] 实现 Header、ThemeToggle、全站搜索与移动导航
- [x] 实现简洁的科协主页开场
- [ ] 实现新闻、通知和活动区块
- [x] 实现科协简介与部门概览
- [ ] 实现独立竞赛平台入口
- [x] 实现加入我们、联系方式占位与页脚（待补充正式联系渠道）
- [ ] 完成桌面端、移动端和三种模式检查
- [ ] 完成键盘操作与基础无障碍检查
- [ ] 运行格式、类型和生产构建检查
- [ ] 完成 Sprint 1 Review、学习回顾与 Retrospective

## Sprint 1 Definition of Done

- 占位页被完整主页 MVP 替换。
- `pnpm check` 与 `pnpm build` 成功。
- 主页在桌面端和移动端均无页面级横向滚动。
- 浅色与深色主题可用，导航栏与页面主体使用同色系轻微分层。
- 主页包含已确认的全部信息区块骨架。
- 内容与组件代码分离。
- 键盘可访问导航、主题切换和主要链接。
- Sprint Review 和学习回顾完成。
