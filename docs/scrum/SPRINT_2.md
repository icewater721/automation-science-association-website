# Sprint 2：文档中心架构

## 状态

规划中。开始日期：2026-08-17。

## Sprint Goal

建立面向新生和低年级学生的学习文档中心：顶部说明文档中心的用途，下方按照学习需求组织资料入口，并用统一目录和内容格式支持后续持续补充。

本轮优先完成信息架构和内容组织方式，只提供保证可用的基础界面，不进行集中式美术精修。

## Sprint Backlog

- [x] 确认文档中心主要面向新生和低年级学生
- [x] 确认文档首页采用“简介 + 学习资料入口”的基本结构
- [x] 确认一级目录只包含“简介”和“学习资料”
- [x] 确认“学习资料”先建立“基础工具 → VS Code”目录
- [x] 设计文档中心的浏览流程与页面结构
- [x] 定义文档元数据和 Markdown 内容模型
- [x] 接入文档中心简介 Markdown
- [x] 建立文档首页、分类页和文档详情页路由骨架
- [x] 实现清爽的折叠式侧边目录和右侧页内跳转
- [ ] 实现面包屑和前后文导航
- [x] 完成第一篇学习资料“VS Code”
- [x] 完成 Git/GitHub、CMake、容器和包管理器的基础资料
- [x] 将当前公开文档接入全站搜索索引
- [ ] 编写开发者新增和更新文档的操作说明
- [ ] 完成类型、格式和生产构建检查
- [ ] 完成 Sprint 2 Review、学习回顾与 Retrospective

## 暂不纳入本轮

- 新闻、通知和活动中心
- 大批量正式文档录入
- 集中的视觉与文案精修
- 手机端真机验收与折叠菜单
- 数据库、登录和内容管理后台
- 独立竞赛平台入口
- 服务中心的正式功能

## Definition of Done

- 导航栏“文档”能够进入正式的文档中心骨架，而不是单一占位页。
- 文档具有明确的分类、标题、摘要、适用对象、更新时间和排序信息。
- 文档首页先介绍文档中心，再展示面向新生的学习资料入口。
- 分类页能够列出所属文档。
- 文档详情页具有侧边目录、面包屑和前后文导航的基础结构。
- 开发者可以通过新增 Markdown 文件添加文档，无需修改页面布局组件。
- 公开文档可以被全站搜索找到。
- 项目中存在新增和更新文档的简明操作说明。
- Astro 类型检查、Prettier 格式检查和生产构建成功。
- Sprint Review 和学习回顾完成。
