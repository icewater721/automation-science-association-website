# Sprint 2：活动中心功能骨架

## 状态

规划中。开始日期：2026-08-17。

## 候选 Sprint Goal

建立“活动”独立页面和结构化信息模型，让开发者可以用统一方式维护新闻、通知和活动，并让访客从导航栏进入和浏览这些内容。

本轮优先跑通结构与功能，只实现保证可用的基础视觉，不进行集中式美术精修。

## 候选 Sprint Backlog

- [ ] 确认“活动”页面的信息架构和新闻、通知、活动三类内容的关系
- [ ] 定义统一的结构化内容字段和示例内容
- [ ] 将导航栏“活动”改为可用的独立页面入口
- [ ] 实现新闻、通知和活动列表及无内容时的空状态
- [ ] 确认是否在本轮实现内容详情页
- [ ] 将活动内容接入全站搜索索引
- [ ] 完成类型、格式和生产构建检查
- [ ] 完成 Sprint 2 Review、学习回顾与 Retrospective

## 暂不纳入本轮

- 集中的视觉和正式文案精修
- 手机端真机验收与折叠菜单
- 数据库、登录和内容管理后台
- 独立竞赛平台入口
- 文档中心与服务中心的正式功能

## 候选 Definition of Done

- 导航栏“活动”可以进入独立页面。
- 页面可以展示新闻、通知和活动三类结构化内容。
- 内容按照日期从新到旧排列。
- 没有某类内容时显示明确的空状态。
- 开发者新增内容时不需要修改列表布局组件。
- 全站搜索能够找到已发布的活动类内容。
- Astro 类型检查、Prettier 格式检查和生产构建成功。
- Sprint Review 和学习回顾完成。

## Sprint Planning 待确认

1. “活动”是三类内容的总入口，还是只指线下活动？
2. 新闻、通知和活动是否共用一个列表？
3. Sprint 2 是否实现详情页，还是先完成列表与内容模型？
4. 是否已有可以用于开发测试的首批内容？
