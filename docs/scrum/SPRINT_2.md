# Sprint 2：文档中心架构

## 状态

规划中。开始日期：2026-08-17。

## Sprint Goal

建立网站文档中心的基础架构，让科协资料能够按照统一分类、目录和内容格式进行维护，为后续逐步补充正式文档做好准备。

本轮优先完成信息架构和内容组织方式，只提供保证可用的基础界面，不进行集中式美术精修。

## Sprint Backlog

- [ ] 确认文档中心的服务对象和主要使用场景
- [ ] 确认一级分类、目录层级和命名规则
- [ ] 设计文档中心的浏览流程与页面结构
- [ ] 定义文档元数据和 Markdown 内容模型
- [ ] 建立文档首页、分类页和文档详情页路由骨架
- [ ] 实现侧边目录、面包屑和基础文档导航
- [ ] 准备少量示例文档，验证架构是否可用
- [ ] 将公开文档接入全站搜索索引
- [ ] 编写开发者新增和更新文档的操作说明
- [ ] 完成类型、格式和生产构建检查
- [ ] 完成 Sprint 2 Review、学习回顾与 Retrospective

## 暂不纳入本轮

- 新闻、通知和活动中心
- 大批量正式文档录入
- 集中的视觉与文案精修
- 手机端真机验收与折叠菜单
- 数据库、登录和内容管理后台
- 独立竞赛平台入口
- 服务中心的正式功能

## Definition of Done

- 导航栏“文档”能够进入正式的文档中心骨架，而不是单一占位页。
- 文档具有明确的分类、标题、摘要、更新时间和排序信息。
- 文档首页可以按分类发现内容。
- 分类页能够列出所属文档。
- 文档详情页具有侧边目录、面包屑和前后文导航的基础结构。
- 开发者可以通过新增 Markdown 文件添加文档，无需修改页面布局组件。
- 公开文档可以被全站搜索找到。
- 项目中存在新增和更新文档的简明操作说明。
- Astro 类型检查、Prettier 格式检查和生产构建成功。
- Sprint Review 和学习回顾完成。

## Sprint Planning 待确认

3. 本轮用哪些示例文档验证目录和详情页？
4. 是否需要提供文件下载，还是先只展示网页文档？
