# Sprint 4：门户重构与成员内容能力

## 状态

已完成。开始于 2026-08-20，Product Owner 于 2026-08-22 确认关闭。

## Sprint Goal

将网站从展示型门户推进为可持续积累内容的科协自留地：统一为简约侧栏结构，保留浅色/深色阅读体验，并加入成员身份、个人主页和受权限保护的文章发布流程。
