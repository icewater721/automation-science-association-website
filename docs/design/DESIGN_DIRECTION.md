# 视觉方向（草案）

## 参考结论

- 清华自动化系学生科协网站采用现代独立门户表达：强首屏、欢迎语、组织部门卡片和较年轻的技术氛围。
- 清华计算机系学生科协网站更强调信息导航、部门职责和可直接获取的内容。
- ASAW 首页适合结合两者：视觉上鲜明简洁，信息上克制且易扫描。

## 品牌起点

Logo 由黑色圆形、白色字母 `A` 与蓝色轨迹构成。网站以黑白及其中性灰构成主要视觉，亮蓝只作为小面积点缀色，避免形成常见的“大面积蓝色科技风”。

## 主题系统

网站同时提供浅色和深色模式，并共享同一套页面结构、组件与内容。

| 当前主题 | 页面主体 | 导航栏   | 主要文字 | 点缀色       |
| -------- | -------- | -------- | -------- | ------------ |
| 浅色模式 | 纯白背景 | 浅灰背景 | 黑色文字 | 少量品牌亮蓝 |
| 深色模式 | 纯黑背景 | 近黑背景 | 白色文字 | 少量品牌亮蓝 |

导航栏与页面主体使用同一明度方向的相邻中性色，通过轻微色差形成边界，不再使用黑白反色。

### 切换规则

- 首次访问默认跟随操作系统主题偏好。
- 用户可以在导航栏中手动切换主题。
- 用户的手动选择保存在本地浏览器中，后续访问优先使用该选择。
- 页面初次加载时避免出现浅色与深色瞬间跳变。
- 两种主题都可使用同一品牌亮蓝点缀，但需分别检查其对比度。

### 色彩使用规则

- 黑、白和中性灰承担页面背景、文字、卡片、边框及主要按钮。
- 品牌亮蓝仅用于 Logo 呼应、主题切换状态、焦点环、少量链接或关键微交互。
- 大面积背景、长段文字和普通内容卡片不使用亮蓝。
- 蓝色不能成为区分信息的唯一手段，需同时配合文字、形状或图标。

## 初步关键词

`克制`、`理性`、`年轻`、`清晰`、`可信`

## 设计约束

- 不照搬参考网站的布局、文案、图片或代码。
- 动效服务于层级和反馈，不做影响阅读的大面积炫技动画。
- 首页需兼顾手机访问、加载速度和无障碍对比度。
- Logo 周围保留足够留白，不将复杂照片直接叠在 Logo 后方。
- 所有主要组件必须同时通过浅色和深色主题验收。
- 不直接在组件中散落颜色值；颜色由语义化设计变量统一管理。
