# 视觉方向

> 当前版本：Sprint 4 结束状态。

## 设计目标

网站希望传达自由、极客、表达欲、传承与积淀，而不是传统学生部门的公告栏或面向领导汇报的宣传页。视觉保持简约、克制和较高信息密度，让真实内容成为主体。

## 页面结构

- 桌面端使用固定左侧栏，集中品牌、搜索、主导航和成员工具。
- 内容区保持充足但不过度空旷的阅读宽度。
- 文档页使用右侧页内目录，不在全站侧栏继续堆叠文档层级。
- 当前页面在导航中提供明确的选中反馈。

## 主题系统

只保留浅色和深色两种主题：

| 主题 | 页面 | 侧栏 | 文字    | 点缀       |
| ---- | ---- | ---- | ------- | ---------- |
| 浅色 | 白色 | 浅灰 | 黑/深灰 | 少量品牌蓝 |
| 深色 | 黑色 | 近黑 | 白/浅灰 | 少量品牌蓝 |

- 首次访问默认浅色。
- 点击侧栏底部图标直接在两种主题间切换，不使用下拉列表。
- 选择保存在本地浏览器，页面加载前应用，避免明显闪烁。
- 色彩通过语义化变量管理，不在组件中无规则散落。

## 文章阅读

- 正文使用标准无衬线字体，中英文混排不随意切换字体。
- 独立代码块使用随站点发布的 Maple Mono。
- 代码块右上角使用无底框复制图标，并提供成功/失败状态。
- 标题、摘要、贡献者、正文和页内目录形成稳定层级。

## 交互原则

- 图标必须有可访问名称和键盘焦点。
- 动效只用于状态和层级反馈，并尊重减少动态效果偏好。
- 浅色与深色均需保持文字、边框和焦点对比度。
- 不使用未经授权的游戏素材、字体或视觉资产。

## 后续重点

- 手机端侧栏与核心流程适配。
- 表单错误、加载和空状态统一。
- 管理页面与公开页面的视觉层级继续收敛。
