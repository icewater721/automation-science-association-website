# 主页与全站侧栏规格

## 页面目标

让访问者确认组织身份、了解科协部门、找到文档/文章与联系方式。网站以内容沉淀为主，不承担 QQ 群即时通知功能。

## 当前信息架构

```text
全站侧栏
├── Logo、组织名称、WUST / AI & AUTOMATION
├── 全站搜索
├── 首页
├── 文档
└── 底部工具
    ├── 登录/个人菜单
    ├── GitHub 仓库
    └── 浅色/深色切换

主页
├── 科协与部门介绍
│   ├── 科创部
│   ├── 赛事部
│   └── 运维部
├── 加入我们
├── 联系我们
└── 页脚
```

## 核心验收标准

### 首页与组织介绍

- Logo 和组织名称可返回首页。
- 主页展示三个部门的真实、精简职责。
- 部门简述和“我们做什么”具有清晰的左右层级。
- 加入与联系方式使用当前确认的信息。

### 侧栏与导航

- 当前页面在导航中具有明确选中状态。
- 搜索位于品牌区域下方。
- 底部从左到右为个人入口、GitHub、主题切换。
- 登录后个人入口变为个人菜单，并按权限显示管理功能。

### 搜索

- 静态索引按标题、分类、摘要和关键词匹配。
- 最多展示六条结果，并具有加载失败和无结果提示。
- 当前尚不搜索 Supabase 动态文章，记录为 Backlog。

### 主题

- 默认浅色，点击图标在浅色与深色之间切换。
- 选择保存在浏览器中。
- 页面加载不出现明显错误主题闪烁。

### 响应式

桌面端侧栏固定。手机端专项体验尚未完成，应在后续 Sprint 验收，不把当前桌面可用错误地写成“手机端已完成”。
