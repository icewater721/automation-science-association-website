# 文档与文章中心规格

## 页面目标

为本校学生和科协成员提供可持续沉淀的学习资料、技术分享、竞赛经验、项目记录与公告。访客无需登录即可阅读；发布操作只向获批管理员开放。

## 当前信息架构

```text
/articles/
├── 全部文章卡片
├── 分类筛选
│   ├── 技术分享
│   ├── 工具使用
│   ├── 竞赛经验
│   ├── 项目记录
│   ├── 公告
│   └── 未分类
└── 文章详情
    ├── 标题、摘要与贡献者
    ├── Markdown 正文
    ├── 右侧页内目录
    ├── 代码字体与复制
    └── 前后文（内置文档）
```

旧 `/docs` 路径由 Astro 重定向到文章中心，避免已有链接失效。

## 内容来源

### 仓库内置文档

- 位于 `src/content/docs/`。
- 使用 Astro Content Collections 校验字段。
- 构建时生成静态详情页，并将元数据和正文写入静态搜索索引。
- 适合稳定、经过代码审查的基础资料。

### Supabase 动态文章

- 位于 `public.articles`。
- 管理员通过网站创建草稿、上传图片并发布。
- 公开 Feed 在浏览器中加载。
- 已发布文章的元数据和正文会在浏览器中并入全站搜索；草稿不公开。

## 文档字段

```text
title          标题
description    摘要
kind           document
category       文章分类
audience       适用对象
order          内置文档顺序
publishedAt    首次发布时间（可选）
updatedAt      更新时间
keywords       搜索关键词
draft          是否仍为草稿
sourceUrl      外部资料来源（可选）
```

## 阅读布局

- 桌面端：全站左侧栏 + 中间正文 + 右侧页内目录。
- 右侧目录根据文章标题生成并跟随滚动高亮。
- 代码块使用 Maple Mono，并在右上角提供无底框复制图标。
- 正文使用标准无衬线字体。
- 手机端专项布局和真机验收仍在 Backlog。

## 发布与权限

```text
普通访客 → 阅读公开文章
登录成员 → 维护个人资料、申请管理员
管理员 → 草稿、发布、删除、图片、申请审核
```

前端显示状态不是安全边界。文章和图片写入必须同时通过 Supabase RLS、角色校验、约束和受控函数。

## 内容原则

- 只收录可以公开给学生的内容。
- 外部资料标明来源，不复制受版权保护的长篇内容。
- 每篇文章解决相对明确的问题，避免只有标题没有有效内容。
- 内容和视觉可以在集中整理 Sprint 中批量校对。
- 评论、公开投稿和协作者工作流尚未设计，不默认开放。
