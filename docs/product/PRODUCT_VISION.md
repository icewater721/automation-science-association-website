# 产品愿景

## 愿景陈述

为武汉科技大学人工智能与自动化学院的学生与科协成员建设一块自由、极客、鼓励表达并能够传承经验的线上自留地。网站不以替代 QQ 通知或校园系统为目标，而是沉淀科协介绍、学习资料、技术文章、项目与竞赛经验。

## 主要用户

### 本校学生

无需登录即可认识科协、阅读文档和公开文章、查找联系方式，并在未来进入活动或外部服务。

### 科协成员

可以创建个人资料、展示公开文章；获得管理员权限后可维护草稿、发布文章和处理权限申请。

## 当前产品范围

```text
公开访问
├── 主页与部门介绍
├── 文档/文章列表与阅读
├── 静态内容搜索
├── 浅色/深色主题
└── 联系与 GitHub 入口

成员能力
├── 邮箱 OTP 登录
├── 个人主页、昵称、个签、头像和背景
└── 已发布文章展示

管理员能力
├── 权限申请与审核
├── 草稿编辑
├── 文章发布与删除
└── 文章图片上传
```

## 明确边界

- 不接入校园统一身份系统。
- 不替代 QQ 群中的即时通知。
- 独立竞赛平台不属于本仓库的业务系统。
- 当前不提供评论、实时聊天、竞赛报名或组队。
- 当前不维护自建后端服务器。

## 近期方向

- 统一静态文档与动态文章的搜索体验。
- 改善手机端、键盘操作和无障碍。
- 逐步增加真实内容，而不是继续堆叠占位功能。
- 在需要时建设活动和服务页面。
