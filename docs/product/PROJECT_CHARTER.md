# 项目章程（草案）

## 项目名称

- 正式名称：`Automation Science Association Website`
- 简称：`ASAW`
- 中文描述：科协门户网站

## 产品定位

武汉科技大学人工智能与自动化学院科学技术协会门户网站，主要面向本校学生与科协成员。网站用于建立组织形象、汇集重要信息，并为后续服务提供统一入口。

## Sprint 0 需求基线

- 第一版仅建设一个公开主页。
- 浏览者无需登录，也不提供登录入口。
- 新闻、通知、活动等内容由科协内部提供，MVP 阶段由开发者更新。
- MVP 不建设管理后台、发布账号和权限系统。
- 未来若非开发人员需要自行发布内容，再单独评估内容管理与内部账号系统。
- 视觉参考清华大学自动化系学生科协与清华大学计算机系学生科协网站，但不复制其视觉资产或页面内容。
- 使用项目提供的黑色圆形、白色字母与蓝色轨迹 Logo 作为品牌视觉起点。

## 已确认边界

- 科协门户与竞赛平台是两个独立项目。
- 门户可以展示竞赛平台入口，但不承载竞赛报名、组队或竞赛数据管理。

## 待确认事项

- 主页各内容区块及其优先级
- 学生访问主页时最重要的具体需求
- 网站正式中文展示名称及是否使用英文副标题
- 首批新闻、通知、活动、组织介绍和联系方式素材
- 独立竞赛平台的名称、URL 与上线状态
- 现有域名、服务器、备案及部署限制
- 首个可发布版本的目标时间
