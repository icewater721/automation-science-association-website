# ADR-0001：MVP 采用 Astro 静态架构

- 状态：Partially Superseded by ADR-0002
- 日期：2026-08-16

## 背景

ASAW MVP 是一个无需登录的公开主页，内容由开发者更新，仅有主题切换和移动导航等少量交互。

## 决策

采用 Astro、TypeScript、原生 CSS 和本地内容集合，在构建阶段生成静态网站；MVP 不建设后端和数据库。

## 结果

### 正面

- 部署简单，运行成本和攻击面较小。
- 页面默认输出静态 HTML，适合内容门户。
- 内容具有结构校验，组件可以复用。
- 未来可以逐步增加交互或更换内容来源。

### 代价

- 每次内容更新都需要重新构建和部署。
- 非开发人员暂时不能自行发布。
- 若未来加入大量登录后功能，需要新增独立的动态架构设计。

## 后续演进

Sprint 4 保留 Astro 静态构建和 GitHub Pages 托管，但加入 Supabase 动态服务。新的运行时边界见 ADR-0002；本 ADR 对静态优先和不自建服务器的决策仍然有效。
